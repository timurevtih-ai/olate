# Сайт кондитерского дома О'ЛАТЕ

Одностраничный сайт: 3D-чашка с латте-артом и летающими макарон на первом экране,
фирменные позиции, полное меню с поиском, торты (целый / кусочек), адреса со статусом «открыто сейчас».

## Как открыть

Откройте `index.html` в браузере. Работает и просто с диска, и на любом хостинге
(GitHub Pages, Netlify, обычный хостинг) — достаточно загрузить папку `olate` целиком.

## Как поменять меню, цены, адреса

Всё лежит в одном файле — `js/data.js`. Правьте названия, цены, описания, телефоны и часы работы,
сохраните файл и обновите страницу. Пересобирать ничего не нужно.

Фото блюд лежат в `img/` (формат `.webp`). Чтобы добавить фото к позиции,
положите файл в `img/` и укажите его имя без расширения в поле `img` нужной позиции.

## Если меняете код (src/)

Код 3D-сцены и интерфейса — в `src/`. После правок пересоберите `js/app.js`:

```bash
npm install
npm run build
```

## Что проверить перед запуском

- Цены взяты из карточек Google (обновлялись 5–7 месяцев назад) и печатного меню — сверьте с актуальными.
- Адреса и часы работы найдены в интернете: проверьте точку на ул. Шоссейной, 75 (город и телефон не нашлись).
- Папка `photos/` — исходные скриншоты, на сайте не используются, её можно не загружать на хостинг.
